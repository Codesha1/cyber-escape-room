# CYBER ESCAPE ROOM — مهمة إنقاذ مختبر البرمجة

لعبة تعليمية تفاعلية لدرس **التكرارات في سكراتش** (الصف الرابع الابتدائي).
مبنية بـ Next.js وقاعدة بيانات PostgreSQL (Supabase)، وتُنشر مجانًا على Vercel.

## الروابط بعد النشر

| الرابط | لمن |
|---|---|
| `/` | الطالبات (اللعبة) |
| `/leaderboard` | شاشة الفصل: الأعداد أثناء اللعب، وحفل الكشف عند الإعلان |
| `/admin` | المعلمة (بكلمة مرور) |
| `/api/health` | فحص سريع أن كل شيء يعمل |

## النشر (حوالي 15 دقيقة)

1. **قاعدة البيانات:** أنشئي مشروعًا مجانيًا في [supabase.com](https://supabase.com).
   من زر **Connect** اختاري **Transaction pooler** (المنفذ 6543) وانسخي الرابط،
   واستبدلي `[YOUR-PASSWORD]` بكلمة مرور قاعدة البيانات.
   لا حاجة لإنشاء جداول؛ اللعبة تنشئها تلقائيًا عند أول تشغيل.
2. **GitHub:** أنشئي مستودعًا جديدًا وارفعي ملفات هذا المجلد (بدون `node_modules` و `.next`).
3. **Vercel:** من [vercel.com](https://vercel.com) اختاري **Add New → Project** واستوردي المستودع،
   ثم أضيفي في **Environment Variables**:
   - `DATABASE_URL`: رابط Supabase من الخطوة 1
   - `ADMIN_PASSWORD`: كلمة مرور لوحة الإدارة
   - `SESSION_SECRET`: نص عشوائي طويل (32 حرفًا على الأقل)
   - اختياري: `APP_TIMEZONE` (الافتراضي `Asia/Riyadh`) لأوقات ملف CSV
4. اضغطي **Deploy**، ثم افتحي `رابطك/api/health`، ويجب أن يظهر `"ok": true`.
   إذا ظهر `false` فستجدين في `checks` اسم المتغير الناقص.

## يوم الحصة

1. افتحي `/admin` وتأكدي أن التسجيل واللعب مفتوحان.
   لبدء اللعب في لحظة واحدة: أغلقي «اللعب»، ودعي الطالبات يسجلن، ثم افتحيه.
2. اعرضي `/leaderboard` على شاشة الفصل واضغطي «تفعيل الصوت».
3. عند الانتهاء فعّلي «إعلان النتائج»، فيبدأ حفل الكشف على كل شاشة مفتوحة.
4. صدّري CSV للاحتفاظ بالنتائج، ثم استخدمي «جولة جديدة» قبل الفصل التالي.

## قواعد اللعب

- ثلاثة أسئلة في غرفتين، بالترتيب، ولا يمكن تخطي أي سؤال.
- الإجابة الخاطئة لا تمنح نقاطًا ولا تخصم شيئًا، ويمكن إعادة المحاولة. الإجابة الصحيحة لا تُكشف أبدًا.
- الإجابات الصحيحة محفوظة في الخادم فقط ولا تصل إلى المتصفح.
- الدرجة من 3. الترتيب: المكتملات أولًا، ثم الدرجة، ثم أقل زمن لعب فعلي، ثم أقل محاولات خاطئة.
- الزمن يُحتسب فقط والصفحة مفتوحة وظاهرة، ويتوقف عند إغلاقها أو عند إيقاف المعلمة للعب.
- بعد الإكمال تكون «إعادة اللعب» جولة تدريب لا تغيّر النتيجة المسجلة.
- «لاعبة جديدة» تتيح لطالبة أخرى اللعب على الجهاز نفسه.

## التشغيل المحلي والاختبارات

```bash
npm install
cp .env.example .env.local   # ثم عدّلي القيم
npm run build && npm start   # http://localhost:3000
# الاختبارات (على خادم يعمل وقاعدة بيانات حقيقية):
BASE=http://localhost:3000 DATABASE_URL=... ADMIN_PASSWORD=... npm test
```
